## Features

- একাধিক Job profile এবং আলাদা Profile Name
- JSON profile Import/Export
- Departmental Status ফাঁকা থাকলে `Not Applicable`
- Profile-এ Same as Present Address checkbox
- SSC/HSC section-specific numeric Roll ও Result mapping
- DOB, Examination, Subject/Degree এবং address autofill
- Local-only storage; no login, document upload, external server বা analytics request

## Install / update

1. ZIP extract করুন।
2. Chrome-এ `chrome://extensions` খুলুন এবং Developer mode চালু করুন।
3. পুরনো unpacked extension remove করে extract করা `source` directory **Load unpacked** করুন।
4. Profile হারানো ঠেকাতে update-এর আগে popup থেকে **Export JSON** করে রাখুন।
